# 医美技术栈 · 可视化设计说明

本目录是系列的配图工作区，产出物分三层。SVG 源文件（fig-00 至 fig-10）用于网页端与 GitHub 展示，走查文件夹是 1x 渲染稿（视觉走查用），公众号导出文件夹是 2x 高清 PNG（宽 2160px，单张 200 至 370KB，微信公众号编辑器不收 SVG，上传用这批）。两个脚本维持整个体系，make_figs.py 从数据生成全部 SVG，render_figs.py 用无头 Chrome 渲染 PNG。

**语义规则。** 颜色只按语义使用。青绿属于医美主体与主线，蓝灰只出现在对标物 SC 一侧，金色专指医疗属性多出的层（三张总图用同一条金色注释贯通），陶土专指边界与风险侧（红线、高危区、急症级）。这套语义在 11 张图里保持一致，读者跨图阅读时不需要重新学习图例。

**版式。** 画布统一宽 1080，圆角 12 至 16，卡片白底细描边（#D9E1DD）。每张图固定三件套，左上角图号胶囊（医美技术栈 · 图 NN）、居中标题与副标题、页脚左右分列系列名与核验时间。字体栈 PingFang SC、Microsoft YaHei、Noto Sans SC，标题 33px 粗体，副标题 16.5px，正文 13 至 16px，最小字号 11px（标签）。层条、卡片、胶囊内的文字都留了不小于 12px 的内边距。

## 工作流

改图永远改 make_figs.py 里的数据与函数，不改 SVG 文件本身。完整流程四步。

1. python make_figs.py，重新生成全部 SVG 并自动做 XML 良构校验。
2. python render_figs.py 1 走查，渲染 1x 稿。
3. 对走查稿做视觉检查，文字是否溢出、元素是否重叠、配色语义是否走样。
4. 确认后 python render_figs.py 2 公众号导出，出高清 PNG。

新增图的做法是复制一个图函数，沿用 page 头、色板常量与 pill、card 等绘图函数，编入 FIGS 字典即可。
