# 医美的技术栈 · 电子刊专题

把美容医生、医美咨询师、医美机构的专业能力画成三张技术栈地图，对标 IT 行业最成熟的栈图体例。医生对标 IT 工程师（七层纵深栈），咨询师对标售前顾问 SC（七层广度栈），机构对标工程组织（八系统组织栈）。专业一旦成为可核对、可学习、可升级的清单，就不再依赖形容词。

线上阅读请开 GitHub Pages 站点（本仓库 Settings → Pages，main 分支 /docs），或直接浏览本仓库的 md 源文件。

## 维护流程

改文章只改三个篇目文件夹与总览的 md。改图先改 `配图/make_figs.py`，跑 `python 配图/make_figs.py` 重新生成全部 SVG。更新网站跑下面两条，docs 随之同步。

```
python 网站/build_site.py
rm -rf docs && mkdir docs && cp 网站/*.html docs/ && cp -r 网站/assets 网站/配图 docs/
```

配图的公众号上传用 PNG 在 `配图/公众号导出/`，由 `python 配图/render_figs.py 2 公众号导出` 重新导出。视觉系统（色板语义、图种清单）见 `配图/可视化设计说明.md`。

## 口径说明

论证只用五类可核验信息，即法规与资质、临床证据与共识、并发症数据、价格量级（标注估算）与监管类别。全部法规与价格信息核验至 2026 年 8 月 18 日，正式发布前需逐条复核。本刊内容不构成医疗与投资建议。
