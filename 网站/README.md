# 医美技术栈 · 静态网站

零依赖静态站，一个 Python 脚本从系列 md 源文件构建。本文件夹可直接整体部署。

## 目录结构

```
网站\
├── build_site.py        构建脚本（唯一维护入口）
├── index.html           首页（构建产物）
├── 00-系列总览.html      …共 12 个页面（构建产物）
├── 01-….html … 10-….html
├── assets\style.css     站点样式（手写文件，可直改）
├── 配图\                从 ..\配图 拷入的 11 张 SVG（构建产物）
└── 走查\                视觉走查截图（桌面与移动各两页，可删）
```

## 构建与更新

改完系列 md 或样式后，在本目录运行 python build_site.py。脚本会重新转换 12 个 md 源（系列根的总览与三个篇目文件夹的十篇正文）、刷新配图拷贝、生成全部页面，并自检每个页面的本地链接与图片引用，缺失即报错退出。

md 到 HTML 的转换覆盖本系列用到的语法（标题、引用摘要、表格、列表、粗斜体、图片加图注、分隔线），附录来源清单自动套虚线卡片样式，../配图/ 路径自动改写为配图/。

## 本地预览

直接双击 index.html 即可（纯静态、无外部依赖、无网络请求）。也可起本地服务：

```
cd 网站
python -m http.server 8000
```

浏览器打开 http://localhost:8000。

## 部署到 GitHub Pages

1. 新建仓库（或用现有站点仓库的子目录）。
2. 把本文件夹内容（不含 走查\）推上去。
3. 仓库 Settings → Pages，选 main 分支根目录（或 /docs）。
4. 中文文件名会被浏览器自动百分号编码，GitHub Pages 原生支持，无需配置。

或者放进现有 sooogooo.github.io 仓库的一个子目录（如 /yimei-stack），访问路径即 https://sooogooo.github.io/yimei-stack/。注意子目录部署时相对路径无需改动，全部是站内相对链接。
